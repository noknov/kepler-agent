# 瑞幸订单流程

使用已注册的瑞幸工具，参数以当前 descriptor/schema 为准。凭据由服务端管理；连接不可用时说明缺少的配置，不从聊天记录或文件提取 token，也不改用 shell/HTTP 绕过工具策略。

- 根据用户提供的位置或明确选择查找门店，不把服务器出口 IP 当成用户位置。只在坐标足够准确时展示距离。
- 从实际商品结果选择商品和 SKU；定制规格先检查可选属性。门店、商品、规格或数量存在实质歧义时，询问必要信息。
- 创建订单前调用预览，核对商品、数量、价格单位和优惠。沿用预览返回的优惠券代码。用户已授权的订单无需重复确认；最终价格超出授权范围、明细变化或结果不完整时，先澄清。
- 创建或取消订单遵守用户授权和服务端工具策略。请求结果不明时先查询订单，避免重复创建或取消。
- 展示真实返回的订单和金额；支付入口使用完整的支付二维码 URL。取餐码和取餐状态以已支付订单的查询结果为准，不预测完成时间。
- 回复包含业务结果和必要的下一步，不输出凭据、原始协议或内部调用过程。
