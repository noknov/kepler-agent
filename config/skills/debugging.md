# Skill: Production Debugging

Use this skill when triaging an outage, customer issue, failed workflow, or suspicious service behavior.

1. Restate the symptom and identify the affected surface, tenant, environment, and time range.
2. Check recent deploys or git changes when the issue correlates with a release.
3. Query logs with narrow filters. Start with errors, then expand only when needed.
4. Read code around the exact error message, route, job, or handler.
5. Produce a short hypothesis list and mark each as supported, contradicted, or unknown.
6. End with concrete next actions and the safest immediate mitigation.
