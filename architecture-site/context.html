上下文与证据

上下文是会话事件的有限投影。投影器选择历史、保留完整交互，并将环境、当前图片和工具定义纳入预算。压缩和任务声明不能替代原始证据。

请求组成

组成来源处理规则
系统提示核心、产品和环境配置与动态输入分层
会话消息用户输入、模型消息和工具结果从会话事件投影
当前环境与图片本次执行的临时上下文参与请求预算
工具定义默认启用和已激活目录激活前检查上下文容量
输出预留模型输出上限与安全预留派发前计入完整请求

提示分层

提示层区分核心规则、产品配置、环境、项目、用户、技能和当前执行。静态层与动态层分别处理缓存。环境专用信息由对应配置提供，不写入共享执行循环。

提示说明不能替代服务端能力策略、工作区检查或上游权限。加载技能不会自动授予工具权限。

上下文预算

每次派发前，执行器检查：消息、环境、当前图片、工具定义、输出预留和安全预留的估算总量不超过上下文窗口。

BoundedProjector 根据事件类型、摘要覆盖点和完整交互分组选择历史。工具调用与结果需要保持配对。当前输入不能因历史裁剪而丢失。

估算限制

本地 token 估算不等于提供方 tokenizer。提供方仍可能因协议或实际计数拒绝请求。

历史遮蔽与压缩

  1. 读取最新有效摘要及其覆盖边界。
  2. 历史过大时，先遮蔽近期完整交互之外的大工具结果，保留预览与证据引用。
  3. 仍超预算时，按完整交互选择可压缩历史。压缩器读取原始证据。
  4. 将摘要作为新事件追加，不覆盖原始会话事件。
  5. 重新投影并检查完整请求。预算仍不满足时，明确返回错误。

context_read 读取当前会话中已记录的工具证据。大结果读取还需验证 artifact 引用的会话和用户作用域。摘要属于历史数据，不能提升为系统指令。

证据读取与作用域

机制读取对象作用域
context_read已记录的历史工具内容块当前调用的会话
托管 artifact外置的大结果会话与用户
本地 artifact会话目录中的受限证据引用当前会话及受限文件根

引用不是任意磁盘路径。读取器检查引用、调用作用域和偏移。内容是否可恢复，取决于原始记录或外置存储是否实际保留。

用户输入图片在原执行中的可见性，不表示恢复时仍有原图。相关持久化规则见执行过程。

任务声明与证据

结构化任务状态保存带来源和 revision 的模型声明。它与压缩摘要分别保留，用于连续执行。

模型声明、任务状态和内容哈希不构成实际完成证明。完成判断仍需对应工具结果、源文件或测试证据；外部副作用未知时需单独核对。

失效与容量边界

情况处理
摘要覆盖边界无效不让摘要隐藏原始历史
单个当前输入已超预算派发前失败，不退回整个上下文窗口
压缩失败只有完整历史仍满足硬预算时才允许继续
证据引用失效明确缺少原始内容，不把预览当作全文
提供方实际计数不同记录请求错误，不能宣称本地估算与提供方完全一致
