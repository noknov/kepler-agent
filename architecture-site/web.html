Web 接入

Web 提供经认证的会话界面。托管工作进程执行模型与工具，浏览器接收事件并呈现结果。Web 使用自己的会话归属、队列准入和恢复规则。

认证与会话归属

浏览器登录、Slack 线程身份和用户的外部集成连接是不同对象。会话服务先确认用户对 conversation 的访问权，再处理执行请求。

外部凭据由对应用户连接和作用域选择。客户端传入的会话或用户字段不能单独构成授权。

准入与持久输入

Web 会话队列区分存储错误、租约错误与权威的会话不存在。临时错误应释放认领，不直接确认丢弃。已经持久保存的终态用于结束确认。

工作进程已满时，不应通过提前认领等待任务消耗其重试次数。准入范围包含持久确认或释放之前的生命周期。

事件与重连

浏览器通过事件流更新运行状态与消息。连接中断不证明执行已取消；界面需要按服务端会话和运行状态恢复。

模型与工具记录属于执行事实。输入草稿、连接状态和实时片段属于呈现状态，不能反向替代终态判断。

关闭与恢复

drain 在生命周期锁下阻止新的准入。服务等待已接收工作及持久确认，再按共享关闭期限取消并清理。

运行结束、队列确认和浏览器收到结果是不同时间点。关闭验证需要覆盖这些边界。

验证范围

现有测试覆盖认证、会话控制、终态失败、恢复和浏览器交互。界面可打开不代表模型、用户集成或流式链路可用。

实际验证需要包含登录、会话提交、消息重连和一次真实模型响应。
