系统架构

Slack、Web 和本地 CLI 共用执行核心。入口适配器处理身份和输入输出；产品配置选择依赖；执行器调度模型与工具，并保存执行事件。

模块职责

模块职责不承担的职责
入口适配器 / Surface身份验证、请求接收、结果投递不复制模型与工具循环
产品配置 / Profile组装存储、凭据、策略、工具和模型客户端不根据界面状态授予权限
执行器 / Runtime构造上下文、调用模型、调度工具、记录终态不依赖 Slack 或提供方协议
适配层转换模型协议，执行工具操作不从模型参数取得认证身份
会话事件记录 / Transcript保存消息与执行生命周期，支持恢复不承担入口调度或实时界面状态

系统调用关系

入口适配器将已认证输入交给产品配置。产品配置组装执行器所需依赖。执行器调用模型与工具，向会话事件存储追加结果。投影与投递读取这些结果。

托管产品在执行前维护持久入口队列。本地 stdio 使用连接生命周期管理已接收工作，二者不具有相同的持久接收保证。

执行状态和前置条件由执行过程定义；组件关系不构成跨系统原子提交。

状态与权限约束

约束含义
执行与投递分离模型或工具完成，不表示用户已收到回复。
事件与投影分离恢复依据会话事件；运行列表用于查询。
发现与授权分离模型能看到工具，不表示当前调用被允许。
未知结果保留工具开始后缺少结果时，外部操作可能已生效。
会话执行串行相同会话的执行不能从同一旧历史并行推进。
