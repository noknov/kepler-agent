01

执行主线上的核心类型

连续会话
一段有顺序的长期对话，是事件记录、会话锁、工具激活和追加输入的共同索引。
SessionID string
一次用户请求
从请求开始到明确结束；内部可以多次请求模型和执行工具。
TurnRequest / TurnResult / TurnID
一次执行轮次
构造一次上下文、请求一次模型；模型要求工具时，执行完工具后进入下一轮。
step int / StepStarted / StepCompleted
会话事件记录
只追加的权威历史，保存恢复和审计所需的完整事实。
transcript.Event / Store
产品组装
把模型、工具、权限、存储、环境和提示内容组合成可运行产品。
profiles/hosted / profiles/local
入口适配
接收外部协议，生成内部请求，并把内部事件转换成用户输出。
surfaces/slack / surfaces/web / appserver

执行请求字段

字段含义注意点
SessionID连续会话编号为空时执行器生成；写入工具作用域
TurnID本次用户请求编号为空时生成；稳定外部编号可用于去重
Input当前用户消息角色必须是用户；持久化时会移除原始图片数据
History首次建立会话时导入的有界历史仅在权威会话为空时写成普通不可信消息
Prompt系统说明片段合成后计算内容摘要
Scope用户、工作区及入口附加值供权限、工具与审计使用
Steering执行中的追加输入来源通过认领与确认接口消费
Parent隔离子任务与父调用的审计关系只进入持久元数据，不进入模型上下文

02

会话事件按用途分组

用途事件值负载重点
会话与请求边界session_started、turn_started、turn_completed、turn_failed、turn_canceled状态、错误、模型、用户、作用域、父任务和追踪编号
执行轮次step_started、step_completed轮次编号和完成方式
输入user_input、steering_input规范消息；追加输入保留来源顺序
上下文context_projected、compaction_created估算字数、消息数、提示摘要、工具数、摘要和覆盖序号
模型逻辑请求model_request_started、model_request_unknown、model_completed、model_failed稳定请求编号、完整结果、用量和失败
模型服务尝试model_attempted提供方、模型、尝试序号、重试或切换结果
模型消息与流assistant_message、model_streamed完整消息持久化；文字片段仅分发
工具tool_call_started、tool_call_completed、tool_call_failed调用编号、稳定执行编号、参数、结果、错误码和耗时
批准approval_requested、approval_resolved权限决定与用户答复
计划与子任务plan_updated、delegated_task_started、delegated_task_completed、delegated_task_failed计划内容、父子关联与子任务结果

每条事件的公共字段

ID 是事件幂等编号；Sequence 是会话内递增序号；SessionID 和可选 TurnID 确定归属；Type 决定负载含义；Timestamp 使用 UTC。可选负载分别承载消息、模型流事件、工具调用、工具结果、计划、状态、错误、JSON 元数据和 W3C 追踪关系。

03

一次请求的结束原因

中文含义内部值触发条件
正常完成completed模型返回最终消息，结束前两次检查都没有新输入
被取消canceled上层取消执行上下文，例如用户中断或处理权丢失
模型错误model_error无法归入更具体类别的模型调用失败
达到执行轮数上限max_steps模型持续请求工具，超过允许轮数
模型输出达到上限output_limit模型回答因长度限制停止且没有工具请求
等待用户批准pending_approval权限层要求批准，当前调用没有同步批准器
等待用户补充pending_input工具结果明确要求用户继续提供信息
模型返回空内容empty_response有限重试后仍无任何内容
时间预算不足budget_exhausted剩余时间不足以开始一次有意义的模型尝试
模型服务暂时熔断provider_circuit_open同一服务和模型连续失败达到阈值
主要与备用模型都失败fallback_exhausted可用的模型路径均已尝试

配置由哪一层负责

配置范围负责内容源码位置
共享执行器执行轮数、工具并发、上下文预算、工具结果大小和重复调用保护packages/agent/runtime/types.go
托管产品模型服务、会话容量、Slack 事件处理、数据库、缓存和工具开放范围packages/config/config.go
本地产品模型、输入路线、输出方式、工作区、执行时间和批准存储packages/profiles/local/config.go
入口请求体、用户输入、订阅缓冲和协议并发等入口限制packages/surfaces、packages/appserver

运行时取值属于部署和用户配置，不在架构说明中重复。这里保留配置归属，便于判断某项行为应该在哪一层修改。

数据库表按职责分类

职责表主要内容
权威执行历史agent_transcript_events会话序号、事件类型、完整 JSON 负载

网页对话web_conversations所有者、标题、会话关联和更新时间
外部连接user_connections、oauth_states加密凭据、提供方状态与 OAuth 事务
用户配置user_settings、user_prompt_assets用户级设置与提示资源
提醒reminders到期时间、处理状态与用户归属
